# Kelishim — ТЗ реестра обещаний аренды

> Статус: утверждён владельцем (approve в чате, 2026-10-29). Схема из 10 полей заморожена; изменения только отдельным решением владельца.

## Цель

Мобильный-first веб-прототип: источники → извлечение условий → сравнение → вопросы хозяину → ответ → итог сделки. Работает без регистрации по публичной ссылке.

## Hero flow (3 мин с телефона)

Старт → «Попробовать на примере» → источники (текст/фото/аудио) → видимый анализ → реестр 10 условий → открыть цитату → вопросы только по `conflict/unknown` → отредактировать сообщение → вручную подтвердить → добавить `owner_reply` → пересчёт → итог сделки.

## FR-1 — FR-8

- **FR-1 Источники:** текст, фото (OCR), аудио (transcribe). Каждый источник хранится с `raw_text`.
- **FR-2 Извлечение:** на каждое из 10 условий — `value, currency, quote, confidence [0..1], hedged`. Отсутствует → `value: null`. Ненулевое значение обязано иметь `quote ⊆ raw_text`.
- **FR-3 Нормализация (кодом, не моделью):** суммы `30 тыс/30 000/30к → 30000` с валютой (сом ≠ USD, не смешивать); сроки → месяцы; животные → `yes/no/negotiable/unknown`.
- **FR-4 Статусы (кодом):** `unknown` (нигде нет), `single` (один источник или hedged), `match` (≥2 совпали после нормализации), `conflict` (≥2 различаются). UI: `❓ Не указано / 🟡 Один источник / ✅ Совпадает / ⚠️ Противоречие`.
- **FR-5 Вопросы и сообщение:** вопросы генерируются только по `conflict/unknown`. Сообщение редактируемо, ничего не отправляется автоматически, готовность только после ручного подтверждения.
- **FR-6 Ответ хозяина:** `owner_reply` — новый источник, реестр пересчитывается кодом.
- **FR-7 Состояния и fallback:** у каждого действия loading/empty/error/success; timeout 30с, max 2 попытки невалидного JSON; сбой → понятный текст + ручной ввод, не белый экран; `confidence < 0.6` или `hedged` → `needs_manual_check` + текстовая метка.
- **FR-8 Demo и честность:** demo-пример проходит полный цикл; сохранённый результат только с меткой «сохранённый результат»; публичные данные обезличены; секрет не во frontend, `.env` не коммитится.

## Схема (freeze, 10 полей)

`rent_amount, deposit, term, utilities, pets, prepayment, repairs, owner_access, termination, deposit_return`

Каждое: `{ value, currency, quote, confidence, hedged, needs_manual_check }`.

## Неподвижное

Не определять мошенничество/риск/собственность/юр. силу; не скрейпить объявления; не слать сообщения автоматически; решение match/conflict — код.

## DoD

Без регистрации по ссылке; demo полный цикл; видны 4 статуса + цитаты; сообщение без ручного подтверждения не готово; постоянная оговорка: «Приложение помогает зафиксировать условия и показывает, что нужно уточнить. Это не юридическая консультация».
