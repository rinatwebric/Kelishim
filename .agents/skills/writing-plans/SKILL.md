# Writing Plans (proxy — full rules apply)

Write plan for engineer with no codebase context. Assume idiomatic code once interface + test known. Document files, names/signatures, spec values, tests per task. DRY/YAGNI/TDD/frequent commits. Save to `docs/superpowers/plans/YYYY-MM-DD-<feature>.md`.

Header, file structure, right-sized tasks (own test cycle + reviewer gate), step = one action + checkable result (fail-test → run-fail → implement → run-pass → commit). Self-review: spec coverage, step scan, type consistency, Review Focus, proportion. Then handoff: ask Subagent-driven vs Native.
