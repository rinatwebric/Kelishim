# Kelishim + Muse Code: быстрый старт

1. Скопируй `AGENTS.md` и каталог `.agents/skills/` в корень репозитория.
2. Положи полное ТЗ в `docs/spec.md`.
3. Запусти Muse Code из корня проекта.
4. Первый запрос:

> Прочитай AGENTS.md, docs/spec.md и skills. Сначала проведи read-only аудит репозитория: определи текущий стек, что уже работает, и что отсутствует для hero flow. Ничего не переписывай. Составь план на вертикальные срезы и начни только с доменной схемы и тестов нормализации/статусов. После изменений запусти тесты и покажи diff.

После каждого среза проси: «запусти тесты, проверь мобильный smoke-flow и не переходи к следующему модулю, пока текущий не работает».

## Важное

- Для проекта нужны реальные адаптеры Muse Voice/Image/Spark, но доменное сравнение должно оставаться обычным кодом.
- Не клади API-ключ во frontend и не коммить `.env`.
- Если в репозитории уже есть стек, сначала адаптируйся к нему; не меняй стек без причины.
- Публичная ссылка и demo должны работать без регистрации.
